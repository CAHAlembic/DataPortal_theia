TROUBLESHOOTING
================================================================================

Issue: "Cannot find module" error
Fix: rm -rf node_modules && npm install

Issue: Build fails with "gyp ERR"
Fix: Install Python and build tools (see BUILDING.md)

Issue: Theme not applying
Fix: Verify alembic-theme.css in resources/, rebuild

Issue: Out of memory
Fix: export NODE_OPTIONS="--max-old-space-size=4096"

For more: See BUILDING.md - Troubleshooting section
